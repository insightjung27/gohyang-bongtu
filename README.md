- 모델 C: 자본경량 애그리게이터 (모국어 UX·수요집계·합배송·에스크로 신뢰·정식 특송/관세 파트너 위탁)
- 다국어(모국어) UX: 한국어/영어/네팔어/크메르어/베트남어/인니어/타갈로그 — 실작동 i18n(자동감지·localStorage)
